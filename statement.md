# Problem Statement
Traditional educational models often fail to identify specific knowledge gaps in real-time. Students proceed through coursework without realizing their foundational weaknesses until formal examinations.

# Scope of the Project
AksharSetu-CLI is a terminal-based diagnostic assessment engine. It evaluates student performance through interactive quizzes, calculates scores dynamically, and maps incorrect answers to specific subject domains to isolate learning gaps. It utilizes multi-threading for batch processing and file I/O for report generation.

# Target Users
*   **Students:** To take diagnostic assessments and receive personalized gap analysis.
*   **Mentors/Educators:** To register students and review cohort performance metrics.

# High-Level Features
1.  **Role-Based Access:** Distinct workflows for Mentors and Students.
2.  **Diagnostic Quizzes:** Dynamic, terminal-based assessment execution.
3.  **Learning Gap Analytics:** Algorithmic mapping of failed questions to core topics.
4.  **Local Report Generation:** Exportable text-based progress reports.
5.  **Concurrent Processing:** Multi-threaded simulation of batch assessment grading.
